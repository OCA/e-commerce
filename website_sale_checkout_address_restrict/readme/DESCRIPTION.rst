This module enhances the Odoo website sale checkout process with two configurable features. First, it allows you to globally disable the "express" checkout option, ensuring that customers must select an address during checkout. Second, it restricts address visibility for portal users linked to child contact partners, so they can only view their own and descendant addresses during checkout, without access to parent or sibling addresses. Parent contacts retain access to all related addresses. These features help streamline the checkout experience and improve delivery accuracy.
