1. Create a contact. Fill in the address and email fields.
2. Create a child contact of the previous one of type 'Delivery Address' or 'Other Address'. Fill in the name, address and email fields. Make sure the child contact has a different email address than the parent.
3. Grant portal acces to both contacts.
4. Navigate to Website > Configuration > Settings and enable the "Filter Shipping for Child Contacts" and "Disable Express Checkout" options.
5. Log in to the website as the parent contact, add an item to the cart and proceed to checkout. You should be redirected to the address selection page, where you can see both the parent and child addresses.
6. Log out and log in to the website as the child contact. Add an item to the cart and proceed to checkout. You should be redirected to the address selection page, where you can only see the child address.
