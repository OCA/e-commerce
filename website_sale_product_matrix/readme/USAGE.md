To use this module, you need to:

1. Go to the configured product web page.
2. You'll se the matrix where you can add units to the cart.

When adding one of these products to the cart from the shop, the product configurator
shows a *Configure options* button instead of the quantity selector. It opens the
matrix filled in with the quantities already in the cart, as in the product page, and
the variants filled in it are listed in the configurator. On confirming it, the cart is
updated with those quantities.
