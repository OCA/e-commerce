This module allows you to display the products purchased regularly by a
user and his company in the online shop.

**Table of contents**

.. contents::
   :local:

Configuration
=============

To set the maximum number of products shown on the *My Regular Products*
page:

1. Go to *Website > Configuration > Settings*, *eCommerce* section.
2. Set *Regular Products Limit*. The default is 10.

The limit is stored in the
``website_sale_menu_partner_top_selling.limit`` system parameter and is
shared by all websites.

The *Regular Products Period (Days)* setting limits how far back orders
are counted: only orders from the last days are taken into account. The
default is 0, which counts all orders. It is stored in the
``website_sale_menu_partner_top_selling.period_days`` system parameter.

The *Regular Products Menu Label* setting changes the label of the link
to the page in the shop and of the card on the customer portal. It is
translatable.

The *Customer Portal Card* setting shows a card linking to the page on
the customer portal home page. It is disabled by default.

For the *My Regular Products* link to appear in */shop*, enable either
the categories sidebar or the top categories bar. The top categories bar
is only displayed when the shop has eCommerce categories.

Usage
=====

1. Log in to the website and go to */shop*.
2. Click the *My Regular Products* link (or the configured label) in the
   categories sidebar or in the top categories bar, or open
   */shop/my_regular_products* directly. Anonymous visitors are
   redirected to the login page.

The page lists the published products ordered by your company (all
contacts of the same commercial partner), sorted by total ordered
quantity in descending order, up to the configured limit. Quantities of
all variants of a product are added together.

Only confirmed sales orders are taken into account. Quotations and
cancelled orders are not counted. If a period in days is configured,
only orders from that period are counted. If
``website_sale_menu_partner_top_selling_pos`` is installed, paid Point
of Sale orders are counted as well.

If the *Customer Portal Card* setting is enabled, a card linking to the
page is shown on the customer portal home page (*My Account*).
