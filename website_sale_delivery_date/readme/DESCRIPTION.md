This module extends the Odoo e-commerce checkout flow by adding a delivery date selector after the customer chooses a delivery method. It is designed for companies that want to allow their customers to specify a desired delivery date when placing an order online.

The selected delivery date is captured directly in the website checkout flow.
Stored on the generated sale order’s commitment_date field (also known as the Delivery Date in the sales backend).
This ensures that the customer's delivery preference is preserved and can be used for order fulfillment, logistics, and scheduling.
