1. Go to **Website fields** on the product form.
2. Select the websites where the product should be available.
3. Click **Go to Website** to preview the product on an assigned website.
   A website explicitly selected in the context takes priority when it is
   assigned to the product. Otherwise, the first assigned website by sequence
   and ID is used, matching the website selector order. This also applies to
   product variants. Products without assigned websites keep the standard Odoo
   navigation behavior.
