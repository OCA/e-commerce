This module lets you define a set of assurance / trust icons that replace the
default 'Terms and Conditions' block on the eCommerce product page.

Instead of the plain text lines ('Terms and Conditions', '30-day money-back
guarantee', 'Shipping: 2-3 Business Days'), the product page displays
configurable benefit cards with an icon and a short text (e.g. 'Free shipping',
'30-day money-back guarantee', 'Terms and Conditions'), each optionally linking
to a page.

Each assurance item can be assigned to a specific website or kept global
(empty website means it is shown on every website).
