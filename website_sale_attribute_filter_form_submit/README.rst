This module allows to configure the website filters in an no automatic
way, so the filters aren't applied until the user explicitly validate
them. It can be set on any needed website.

Only supports attribute filters.

**Table of contents**

.. contents::
   :local:

Configuration
=============

To configure this module, you must do the following:

1. Go to the frontend URL /shop of the website.
2. Open the web editor and in the “Customize” tab, enable the *Manual
   filters* option.

Usage
=====

When manual filter are active, the user can set as many filters as
desired and then hit the submit button to apply them. This allows to set
several filters at once, which isn't always possible with the automatic
behavior.
